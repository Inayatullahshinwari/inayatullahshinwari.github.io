# 👨‍💻 Inayatullah — Personal Portfolio

My personal portfolio website showcasing my skills, projects, and experience as a full-stack developer.

## 🚀 Live Demo
Visit: [inayatullahshinwari.github.io](https://inayatullahshinwari.github.io)

## ✨ Features
- Modern, clean design with smooth animations
- Dark/light mode with persistence
- Fully responsive (mobile, tablet, desktop)
- Single HTML file — zero build step
- Built with Tailwind CSS + Alpine.js

## 🛠️ Tech Stack
- **Tailwind CSS** (via CDN)
- **Alpine.js** (via CDN)
- **Google Fonts** (Inter & JetBrains Mono)

## 📦 Deployment
This site is deployed via **GitHub Pages**. Push to the `main` branch and it auto-deploys.
